# Outlast Vanguard

浏览器端俯视角自动指挥战术模拟游戏。指挥一支由多兵种组成的小队，在尸潮中执行救援、坚守、突围和清剿任务。

## 游戏特性

- 18 种玩法和对应地图，涵盖平民救援、据点防守、尸潮坚守、突围、首领挑战及部队火力挑战。
- 13 种兵种：步枪手、机枪手、喷火兵、榴弹兵、医疗兵、侦察兵、盾卫、霰弹兵、狙击手、工兵、无人机侦察员、军官和弹药兵。
- 本地规则 AI 自动执行小队战术、目标分配、寻路、战斗、救援、治疗和撤离。
- 支持自定义兵种编制、尸潮压力和地图种子；相同种子及设置可复现模拟战局。
- 固定步长模拟、空间索引和 A* 寻路，支持最多 500 名队员的自定义编制。
- 可选接入 OpenAI 兼容的聊天补全 API，由 LLM 提供战术指挥；对局失败时可自动生成战败复盘。
- Canvas 实时展示战场、单位状态、枪火、感染、尸潮和指挥日志。

## 环境要求

- Node.js 20.19+ 或 22.12+
- npm

## 本地运行

```bash
npm install
npm run dev
```

Vite 会显示本地开发地址。生产构建和预览：

```bash
npm run build
npm run preview
```

## 模拟控制

1. 选择玩法模式并调整尸潮压力。
2. 可在“自定义本关兵种数量”中调整编制，每局最多 500 名队员。
3. 输入地图种子并应用，即可复现相同种子下的地图与模拟随机序列。
4. 点击“开始任务”运行，使用“暂停”或“随机新战局 / New Deployment”控制模拟。

## LLM 配置

在“第三方 LLM 接入”面板填写 OpenAI 兼容 API Base URL、模型名称和 API Key，然后点击“应用设置”。启用“LLM 自动指挥”后，模型会参与战术决策；即使关闭自动指挥，只要模型信息完整，任务失败后仍会请求战败复盘。

模型 API Key 保存在当前浏览器标签页会话中，并会随请求发送给所填写的服务商。浏览器直连服务需要服务商允许 CORS。不要把真实 API Key 写入源码或提交到仓库。

## 测试与性能基准

运行自动化用例：

```bash
npm test
```

运行 500 个活跃单位的多模式性能基准：

```bash
npm run benchmark
```

基准覆盖救援、坚守和千尸围攻场景，输出模拟更新耗时 P50、P95、最大值和超过 16 ms 的比例，并检查 P95 不高于 8 ms、超过 16 ms 的比例低于 1%。

## 项目文件

- `src/game/`：世界模拟、模式和地图、寻路、空间索引、战斗与随机数。
- `src/ai/`：本地规则指挥和可选 LLM 指挥、战败复盘。
- `src/render/`：Canvas 战场渲染。
- `src/game/game-core.test.ts`：模拟、随机数、寻路和模式用例。
- `src/game/performance.test.ts`：多模式性能基准。
- `需求文档-自动指挥尸潮救援游戏.md`：玩法和系统需求。
- `演示.mp4`：项目演示视频。

## 技术栈

TypeScript、Vite、HTML Canvas 和 Vitest。
